LIGHT NOVEL DOWNLOADER

Baixe e organize sua leitura

Escolha uma fonte, defina o intervalo e salve os capítulos no seu computador.

1

Pasta de destino

Escolha onde salvar os arquivos ou de onde ler os TXT existentes.

Os arquivos TXT serão gravados nesta pasta.
2

Fonte e capítulos

Detectamos o site pelo endereço informado.

A fonte será identificada quando você informar o link.

Qual link devo usar?
  • Central Novel: URL base terminada em hífen, por exemplo https://centralnovel.com/sua-obra-capitulo-.
  • Free Web Novel: link real de um capítulo, por exemplo https://freewebnovel.com/novel/captured-by-the-cold-detective-bl/chapter-1. Não use nome-da-obra como slug.

O capítulo final deve ser igual ou maior que o inicial.

3

Nome do arquivo

Informe um nome fácil de reconhecer para o livro.

Ajustes avançados de rede

Ajuste apenas se necessário. Mais conexões podem aumentar bloqueios no site.
